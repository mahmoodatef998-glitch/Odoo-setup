## 1. الهدف
أي حد في 4U يفتح شاشة واحدة ويعرف:
- **كل Job Order واقف فين**: طلب المواد اتعمل؟ المشتريات طلبت من مين؟ القطع وصلت؟ اتصرفت للمصنع؟ المولد اتجمّع واتفحص؟ اتسلّم؟
- **كل خطوة اتعملت إمتى ومين عملها، والتأخير حصل فين بالظبط**.

## 2. الأرقام اللي بتربط كل حاجة ببعض ✅
| الرقم | مين بيفتحه | مثال | بيتشاف فين |
|---|---|---|---|
| **رقم البيع (SO)** | المبيعات، بالترتيب | `4U-SO-001` ✅ | العرض، الفاتورة، التسليم |
| **رقم التصنيع (Job Order)** = "الـ PO بتاع المولد" | أوتوماتيك من الـ SO | `4U-PO-001` ✅ | الأمر، **طلب المواد**، **كل PO للقطع**، الاستلام، الصرف، كارت المولد |
| **رقم الشراء (Purchase Order)** = "الـ PO بتاع المشتريات" | المشتريات | `P00001` (زي `P00947` في النموذج) ✅ | Purchase › Orders، وكل سطر مكتوب عليه الـ Job Order |

- **الـ PO بتاع المشتريات غير الـ PO بتاع المولد**: كل واحد في قسمه وبترقيمه، والربط بينهم إن سطر الشراء مكتوب عليه رقم المولد.

- **الـ Job Order بيفضل بنفس الرقم لحد ما يتقفل.**
- **طلب المواد مكتوب عليه رقم الـ Job Order**، وكل PO بيتعمل منه مكتوب عليه "للأمر `4U-PO-001`".
- **الـ serial بتاع المولد = رقم الـ Job Order.** ومفيش سيريال للمحرك أو الـ alternator، فالمخزن مش هيكتب أي أرقام ✅ J10.

## 4. حالة الـ Job Order (`x4u_job_state` على `mrp.production`، computed stored)
| الحالة | امتى | مين بيحركها |
|---|---|---|
| **Waiting Parts** | الأمر اتأكد، وفيه قطعة على الأقل لسه ماوصلتش | أوتوماتيك |
| **Parts Ready** | التلات قطع اتسلّموا ومحجوزين للأمر، ولسه ماتصرفوش | أوتوماتيك (بعد آخر استلام) |
| **Material Delivered** | "Pick Components" اتعمله Validate: القطع اتصرفت للمصنع واتخصمت من مخزن القطع | المخزن |
| **Assembled & Tested** | الأمر اتقفل (Done): المولد دخل المخزن برقم الـ Job Order | المصنع |
| **Finished** | المولد اتسلّم للعميل (كارت المولد بقى Delivered) | المخزن (Validate التسليم) |
| **Cancelled** | الأمر اتلغى | — |

ومعاها **Late** كـ filter: عدّى تاريخ التسليم المتوقع (`date_deadline` من الـ SO) ولسه مش Finished.

## 5. طلب المواد والشراء ✅
```
Job Order 4U-PO-001 اتأكد
  ← طلب مواد أوتوماتيك (Purchase Request) "للأمر 4U-PO-001": Engine + Alternator + Body (والكميات)
  ← المشتريات تختار لكل سطر: المورد، السعر، الكمية ← Create RFQ (ممكن كل قطعة من مورد مختلف)
  ← موافقة المدير العام على كل PO ← Confirm ← الاستلام محجوز للأمر 4U-PO-001 بس
```
| # | القاعدة | الحالة |
|---|---|---|
| P1 | **موردين كتير**، والمشتريات بتحدد لكل طلب: المورد، والمنتج، والسعر، والكمية. ومش لازم يكون فيه مورد ثابت على المنتج | ✅ |
| P2 | **طلب المواد بيتعمل لوحده** من الـ Job Order (المكونات عليها "Purchase Request" ✓)، ومكتوب عليه رقم الأمر | ✅ |
| P3 | **الـ PO مربوط بالأمر**: Source Document = `4U-PO-001`، واللي بيتستلم بيتحجز للأمر ده بس | ✅ |
| P4 | لو القطعة موجودة في المخزن، تتاخد منه، ومتدخلش في طلب المواد (J3) | ✅ |
| P5 | **الأسعار** بتتسجل في Odoo. والمورد والسعر اللي اتطلب بيهم يتحفظوا على المنتج كمرجع للمرة الجاية (Vendor Pricelist) | ✅ |
| P6 | طلب المواد **من غير موافقة منفصلة**: بيبقى Approved لوحده، و**الموافقة الوحيدة هي موافقة المدير العام على الـ Purchase Order** اللي الـ purchaser عمله | ✅ |
| P7 | **وقت الموافقة بيتحدد طريقة الدفع**: Payment Mode (Cash / PDC / Bank Transfer) + Payment Terms (مثلًا 60 Days). ومينفعش الـ PO يتأكد من غير ما الاتنين يتحددوا. ده بيتنفّذ في M3 (`x4u_purchase_approval`)، والـ PDC بيكمّل في `x4u_account_pdc` | ✅ |

لكل قطعة في الأمر بيظهر: الدور (Engine / Alternator / Body)، والمنتج، وسطر طلب المواد، والـ PO (رقمه ومورده وحالته) أو From Stock، والميعاد المتوقع، والحالة: Requested ← Ordered ← Received ← Delivered to factory.
وعلى قائمة الـ Job Orders 3 أعمدة: Engine، Alternator، Body.

## 7. التوقيتات ومكان التأخير ✅
### 7.1 سجل الأحداث (`x4u.job.order.event`)
كل خطوة بتتسجل **لوحدها**: إمتى، ومين، وأنهي مستند.

| # | الحدث | بيتسجل لما |
|---|---|---|
| E1 | Order opened | الـ SO اتأكد |
| E2 | Job Order created | الأمر اتعمل (`4U-PO-001`) |
| E3 | Material request created | طلب المواد اتعمل لوحده |
| E4 | RFQ created (لكل PO) | المشتريات عملت الطلب من المورد |
| E5 | PO approved | انت وافقت |
| E6 | PO confirmed / sent | الـ PO اتأكد واتبعت للمورد |
| E7 | Part received (لكل قطعة) | المخزن عمل Validate للاستلام |
| E8 | Parts Ready | آخر قطعة وصلت |
| E9 | Material Delivered | المخزن صرف القطع للمصنع |
| E10 | Assembled & Tested | المصنع قفل الأمر |
| E11 | QC passed / failed | الجودة قفلت الفحص |
| E12 | Delivered to customer | التسليم اتعمله Validate |

### 7.2 المدد بين الخطوات
| المرحلة | من ← إلى | بتقيس مين |
|---|---|---|
| Purchasing | E3 ← آخر E4 | المشتريات (اختيار المورد وعمل الطلبات) |
| Approval | E4 ← E5 | الموافقة |
| Supplier delivery | E6 ← E8 | الموردين (وكل مورد لوحده) |
| Warehouse issue | E8 ← E9 | المخزن |
| Assembly & test | E9 ← E10 | المصنع |
| QC | E10 ← E11 (passed) | الجودة |
| Dispatch | E11 ← E12 | التسليم |
| **Total** | E1 ← E12 | الدورة كلها |

### 7.3 التأخير فين بالظبط
- مدة مستهدفة لكل مرحلة (Settings، بالأيام). وكل Job Order بيبين **أول مرحلة عدّت المستهدف** = "Delay at".
- اقتراحي: نقيس شهر أو اتنين، وبعدين نحط المستهدف على أساس المتوسط الحقيقي. 🟡

### 7.4 التقارير (وكلها تتصدّر Excel)
- **Timeline**: تاب في الـ Job Order فيه الأحداث بالترتيب.
- **Job Order Analysis**: متوسط كل مرحلة بالشهر أو الموديل أو العميل أو **المورد** (مثلًا "المورد X متوسط توريده 9 أيام").
- **Delays**: الأوامر المتأخرة، ومرحلة التأخير، وكام يوم.

## 8. الشاشات
- **Manufacturing › Job Orders**: list + kanban + form.
  - **List**: رقم الـ Job Order، رقم البيع، العميل، الموديل، Open/Canopy، الـ alternator، الحالة، Engine، Alternator، Body، تاريخ التسليم المتوقع، Delay at.
  - **Filters**: الحالات، Late، Delayed. وGroup by: العميل، الموديل، الحالة، مرحلة التأخير، المورد.
- **الـ Form**: شريط الحالة، Smart buttons (Sales Order، Material Request، Purchase Orders، Generator Card)، وتاب Parts، وتاب Timeline.
- **Purchase › Material Requests**: كل طلبات المواد، وكل سطر عليه رقم الـ Job Order.
- **Manufacturing › Reporting**: Job Order Analysis و Delays.

## 10. الصلاحيات
- الحقول على الـ MO بصلاحيات الـ Manufacturing. وطلبات المواد بصلاحيات `purchase_request` (Request User / Manager).
- `x4u.job.order.event`: قراءة بس، ومحدش يعدّل أو يمسح الأحداث.
- المبيعات: تشوف الـ Job Orders read-only.
- المشتريات والجودة: group **Job Orders: Read Only** (`group_x4u_job_order_viewer`)، بيفتحوا الأمر من التنبيه، وليهم لينك Job Orders في Purchase وفي Quality Control. اتضاف 2026-10-22 (دليل الأدوار، R1).
