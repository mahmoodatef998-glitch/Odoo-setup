# الشغل موديول موديول

بدل ما نشتغل على كل حاجة مع بعض، بنمسك موديول واحد في Odoo ونقفله للآخر، وبعدين نروح للي بعده.

## الخطوات لكل موديول (نفس الترتيب كل مرة)
1. **الدورة**: الشغل ماشي إزاي في 4U النهارده، وهيمشي إزاي في Odoo.
2. **الإعداد**: كل setting وحالته. الإعداد بيتعمل **كود** في `x4u_setup_base` / `x4u_setup_4u`، مش ضغطات في الشاشة، علشان يتعاد زي ما هو على الـ staging والـ production.
3. **البيانات الأساسية**: العملاء، المنتجات، الأسعار… وشكل الـ Excel اللي هتتملي منه.
4. **المستندات المطبوعة**: شكلها ومحتواها (عربي / إنجليزي).
5. **الصلاحيات**: مين يشوف إيه ومين يعمل إيه.
6. **التقارير**.
7. **الـ gaps**: اللي Odoo مش بيعمله ← spec ← موافقتك ← كود (`x4u_...`) + tests.
8. **سيناريو اختبار** نمشيه سوا على `odoo4u_base`، وبعده **sign-off** منك، وساعتها الموديول يتقفل.

- أي قرار يتسجل في ملف الموديول هنا، والقرارات الكبيرة في الـ [blueprint](../phase1/business-blueprint.md) كمان.
- العلامات: ✅ اتعمل · 🟡 مستني قرارك · 🔵 مستني المحاسب · ❌ لسه · ⏳ مش دلوقتي
